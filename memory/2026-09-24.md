# 2026-09-24 微信推送服务故障排查与固化记录

## 1. 核心报错根因
- 现象：sendMessage ret=-2 errmsg=prepare failed
- 真相：并非参数语法错误或消息字数超限。根因是腾讯微信 iLink 协议的 48 小时 context_token 活跃失效机制。
- 解法：当超过 48 小时无双向交互时，用户只需在手机微信上给 Bot 发一条任意消息，即可激活 context_token。

## 2. OpenClaw CLI 调用规范
- --channel 必须 strictly 指定为 openclaw-weixin。
- 严禁使用 --account 参数。
- --target 必须带有 @im.wechat 后缀。
